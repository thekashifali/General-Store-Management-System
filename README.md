# 🛒 General Store Management System
### *A Robust ERP Solution for Retail Efficiency*

The **General Store Management System** is a professional, database-driven desktop application designed to streamline retail workflows. Built using **Python** and **MySQL**, it provides a centralized platform for managing inventory, tracking sales, and maintaining secure user roles.

---

## 🚀 Key Features
* **Inventory Tracking**: Real-time monitoring of stock levels, categories, and pricing.
* **Sales Management**: A streamlined Point of Sale (POS) interface for processing transactions.
* **Database Integration**: Secure data persistence using MySQL for transaction history.
* **Role-Based Access**: Distinct permissions for Admin and Seller roles to protect sensitive store data.

---

## 👥 User Roles & Permissions
Following the **Role-Based Access Control (RBAC)** principle, the system defines two primary users:

### 1. Admin
* **User Management**: Create, suspend, or delete seller accounts.
* **System Oversight**: Access high-level analytics on sales trends and inventory.
* **Full Control**: Manage all product listings and database configurations.

### 2. Seller
* **Order Processing**: Search for items and finalize customer transactions.
* **Status Tracking**: Monitor active transactions and personal order history.
* **Profile Management**: Update personal contact information and credentials.

---

## 🛠️ Tech Stack
* **Language**: Python (Core Logic and GUI).
* **Database**: MySQL (Relational Data Management).
* **Architecture**: Modular design with a clear separation of UI and Logic.
